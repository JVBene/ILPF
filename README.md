# Integrated-Language-with-Python-and-Flashcards---ILPF
🇧🇷️ pt-BR
O objetivo é desenvolver um sistema automatizado para a geração de flashcards contendo palavras aleatórias em inglês e suas respectivas traduções, com integração ao Anki.

O sistema será desenvolvido utilizando HTML, CSS e JavaScript para a interface, além de Python para a lógica de processamento e a comunicação com a API do Anki. Também será utilizada uma inteligência artificial para selecionar palavras com base no nível de conhecimento do usuário, considerando seu progresso de aprendizagem, a fim de promover a ampliação gradual do vocabulário diário.

O funcionamento será baseado em uma interface interativa na qual o usuário poderá pressionar um botão para receber uma nova palavra em inglês, acompanhada de sua tradução. Após a geração, o flashcard correspondente será adicionado automaticamente a um baralho previamente definido na conta do usuário no Anki.

Dessa forma, pretende-se criar uma ferramenta de aprendizagem personalizada e automatizada, capaz de adaptar a seleção de vocabulário ao conhecimento individual do usuário e facilitar a aquisição contínua de novas palavras em inglês.

🇺🇸️ en-US
The goal is to develop an automated system for generating flashcards containing random English words and their respective translations, integrated with Anki.

The system will be developed using HTML, CSS, and JavaScript for the interface, as well as Python for the processing logic and communication with the Anki API. Artificial intelligence will also be used to select words based on the user’s proficiency level, taking into account their learning progress, in order to promote the gradual expansion of their everyday vocabulary.

The system will operate through an interactive interface where the user can press a button to receive a new English word, accompanied by its translation. Once generated, the corresponding flashcard will be automatically added to a deck previously defined in the user’s Anki account.

The goal is to create a personalized and automated learning tool capable of adapting vocabulary selection to the user’s individual knowledge and facilitating the continuous acquisition of new English words.
