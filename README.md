# Integrated-Language-with-Python-and-Flashcards---ILPF
Desenvolver um sistema automatizado com HTML, CSS, JavaScript, Python e inteligência artificial para selecionar palavras em inglês conforme o nível de conhecimento do usuário, apresentar suas traduções e adicionar automaticamente os flashcards gerados a um baralho no Anki, promovendo a expansão diária do vocabulário.
